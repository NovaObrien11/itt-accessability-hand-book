An accordion is a vertically stacked set of interactive headings that each contain a title, content, or thumbnail. It is a highly effective pattern for organizing dense content, but custom accordions are frequently built with major accessibility flaws, such as using non-semantic elements for triggers, missing ARIA state attributes, or blocking keyboard focus.

This guide details how to build fully accessible accordions using standard WAI-ARIA specifications, and shows how you can use native HTML elements to achieve the same result with zero JavaScript.

### Keyboard Interaction Guide
- **Tab**: Moves focus to the next interactive element. Accordion headers are in the natural tab order.
- **Space / Enter**: Toggles the expansion state of the focused accordion panel.
- **Down Arrow**: Moves focus to the next accordion header.
- **Up Arrow**: Moves focus to the previous accordion header.
- **Home**: Moves focus to the first accordion header.
- **End**: Moves focus to the last accordion header.

---

## The WAI-ARIA Accordion Pattern

To make custom accordions fully accessible to screen readers, you must establish correct semantic roles, relationships, and state attributes.

| Attribute | Applied To | Purpose |
| :--- | :--- | :--- |
| `<h3>` (or other heading) | Accordion Header | Wraps the button. Headings must maintain a logical outline structure on the page. |
| `role="button"` (or `<button>`) | Header Trigger | Identifies the element as an interactive button. Using a native `<button>` is highly recommended. |
| `aria-expanded="true\|false"` | Header Trigger | Programmatically announces whether the associated panel is open or closed. |
| `aria-controls="[panel-id]"` | Header Trigger | Programmatically links the button to its corresponding content panel. |
| `role="region"` | Content Panel | Identifies the panel as a landmark region, allowing screen reader users to jump directly to it. |
| `aria-labelledby="[trigger-id]"` | Content Panel | Labels the region using the text of the corresponding header button. |

---

## Keyboard Navigation Specifications

A compliant accordion component must support the following keyboard behaviors:

### 1. Header Navigation
Since accordion headers are interactive buttons, they must be in the natural tab order (`tabIndex={0}`). Users can navigate between headers using the `Tab` and `Shift + Tab` keys.

### 2. Arrow Key Navigation (Optional but Recommended)
To improve usability, users should be able to navigate between accordion headers using the `ArrowUp` and `ArrowDown` keys. Pressing `Home` should move focus to the first header, and `End` should move focus to the last header.

### 3. Activating Panels
When focus is on an accordion header, pressing `Space` or `Enter` must toggle the visibility of the corresponding content panel.

---

## WCAG 2.2 Success Criteria Mapping

Implementing the ARIA Accordion pattern satisfies several key WCAG success criteria:

### 1.3.1 Info and Relationships (Level A)
The semantic headings (`<h3>`), roles (`button`, `region`), and relationship attributes (`aria-controls`, `aria-labelledby`) ensure that assistive technologies can programmatically determine the structure and relationships of the accordion.

### 2.1.1 Keyboard (Level A)
All accordion headers can be focused and toggled using only a keyboard.

### 2.4.7 Focus Visible (Level A)
The accordion headers have highly visible, custom focus indicators when focused via keyboard navigation.

### 4.1.2 Name, Role, Value (Level A)
The role, state (`aria-expanded`), and accessible name of each accordion header are programmatically determinable by assistive technologies.

## React + TypeScript Implementation

Here is a clean, production-ready React component implementing the accessible accordion pattern. It uses a modern CSS Grid transition to animate the panel height smoothly without layout shifting.

```tsx
import React, { useState, useRef } from 'react';

interface AccordionItem {
  id: string;
  title: string;
  content: React.ReactNode;
}

interface AccessibleAccordionProps {
  items: AccordionItem[];
  allowMultiple?: boolean;
}

export const AccessibleAccordion: React.FC<AccessibleAccordionProps> = ({ 
  items, 
  allowMultiple = false 
}) => {
  const [openIndexes, setOpenIndexes] = useState<number[]>([0]);
  const triggerRefs = useRef<(HTMLButtonElement | null)[]>([]);

  const toggleItem = (index: number) => {
    if (openIndexes.includes(index)) {
      if (allowMultiple) {
        setOpenIndexes(openIndexes.filter((i) => i !== index));
      } else {
        setOpenIndexes([]);
      }
    } else {
      if (allowMultiple) {
        setOpenIndexes([...openIndexes, index]);
      } else {
        setOpenIndexes([index]);
      }
    }
  };

  const handleKeyDown = (event: React.KeyboardEvent<HTMLButtonElement>, index: number) => {
    let newIndex = index;

    if (event.key === 'ArrowDown') {
      newIndex = (index + 1) % items.length;
    } else if (event.key === 'ArrowUp') {
      newIndex = (index - 1 + items.length) % items.length;
    } else if (event.key === 'Home') {
      newIndex = 0;
    } else if (event.key === 'End') {
      newIndex = items.length - 1;
    } else {
      return;
    }

    event.preventDefault();
    triggerRefs.current[newIndex]?.focus();
  };

  return (
    <div className="accordion-container">
      {items.map((item, index) => {
        const isOpen = openIndexes.includes(index);
        return (
          <div key={item.id} className="accordion-item">
            <h3 className="accordion-header">
              <button
                id={`accordion-trigger-\${item.id}`}
                ref={(el) => { triggerRefs.current[index] = el; }}
                aria-expanded={isOpen}
                aria-controls={`accordion-panel-\${item.id}`}
                onClick={() => toggleItem(index)}
                onKeyDown={(e) => handleKeyDown(e, index)}
                className="accordion-trigger"
              >
                <span>{item.title}</span>
                <svg
                  width="16"
                  height="16"
                  viewBox="0 0 24 24"
                  fill="none"
                  stroke="currentColor"
                  strokeWidth="2.5"
                  strokeLinecap="round"
                  strokeLinejoin="round"
                  className={`accordion-icon \${isOpen ? 'open' : ''}`}
                  aria-hidden="true"
                >
                  <polyline points="6 9 12 15 18 9" />
                </svg>
              </button>
            </h3>
            <div
              id={`accordion-panel-\${item.id}`}
              role="region"
              aria-labelledby={`accordion-trigger-\${item.id}`}
              className={`accordion-panel \${isOpen ? 'open' : ''}`}
            >
              <div className="accordion-panel-content">
                <div className="accordion-inner-content">
                  {item.content}
                </div>
              </div>
            </div>
          </div>
        );
      })}
    </div>
  );
};
```
