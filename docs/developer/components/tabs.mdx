Tabs are a common interface pattern used to organize content into logical groups, allowing users to view one group at a time. However, custom tabs are frequently implemented in ways that block keyboard users and screen readers.

This guide explains how to build fully compliant tabs using standard ARIA patterns and showcases how Docusaurus's built-in features make this straightforward.

### Keyboard Interaction Guide
- **Tab**: Focuses the active tab button. Pressing Tab again moves focus into the active tab panel.
- **Right Arrow**: Moves focus to the next tab and activates it.
- **Left Arrow**: Moves focus to the previous tab and activates it.
- **Home**: Moves focus to the first tab and activates it.
- **End**: Moves focus to the last tab and activates it.

## The WAI-ARIA Tabs Pattern

To make custom tabs accessible, you must establish the correct relationships, roles, and keyboard behaviors using ARIA attributes.

| Attribute | Applied To | Purpose |
| :--- | :--- | :--- |
| `role="tablist"` | Container element | Identifies the element as a container for a set of tabs. |
| `role="tab"` | Tab button elements | Identifies the element as an interactive tab trigger. |
| `role="tabpanel"` | Content container elements | Identifies the element as the container for a tab's content. |
| `aria-selected="true\|false"` | Tab button elements | Indicates which tab is currently active and selected. |
| `aria-controls="[panel-id]"` | Tab button elements | Programmatically associates the tab with its corresponding content panel. |
| `aria-labelledby="[tab-id]"` | Content container elements | Programmatically labels the tab panel using the corresponding tab's text. |
| `tabIndex={0}` | Active tab & panels | Places the active tab button and the panels in the natural keyboard tab order. |
| `tabIndex={-1}` | Inactive tabs | Removes inactive tab buttons from the tab order so users can navigate them with arrow keys. |

---

## Keyboard Navigation Specifications

A compliant tab component must support the following keyboard interactions:

### 1. Arrow Key Navigation (Roving tabindex)
Only the active tab should be focusable via the `Tab` key (`tabIndex={0}`). All other tabs must have `tabIndex={-1}`. When a tab button has focus, users navigate between tabs using the `Left Arrow` and `Right Arrow` keys. 

### 2. Automatic vs. Manual Activation
In our implementation, we use **automatic activation**, where moving focus to a tab with arrow keys automatically selects and displays that tab. This is the recommended pattern for tabs where content loads instantly.

### 3. Focusable Tab Panels
If a tab panel contains static text with no focusable elements (like links or buttons), the panel itself must have `tabIndex={0}`. This allows keyboard users to focus the panel so they can scroll its content using the keyboard arrow keys, and ensures screen readers can easily read the content.

## WCAG 2.2 Success Criteria Mapping

Implementing the ARIA Tabs pattern satisfies several key WCAG success criteria:

### 1.3.1 Info and Relationships (Level A)
The semantic structure (`tablist`, `tab`, `tabpanel`) and relationship attributes (`aria-controls`, `aria-labelledby`) ensure that screen readers understand how the tab headers relate to the content panels, even when the visual layout changes.

### 2.1.1 Keyboard (Level A)
All tab triggers and panels can be accessed and operated entirely using a keyboard.

### 2.4.3 Focus Order (Level A)
Keyboard focus moves in a logical, predictable sequence: from the tab list to the active tab, then to the active tab panel, and finally to any focusable elements inside the panel.

### 2.4.7 Focus Visible (Level A)
Both the tab buttons and the tab panels have highly visible, custom focus indicators when focused via keyboard navigation.

### 4.1.2 Name, Role, Value (Level A)
The role, state (`aria-selected`), and accessible name of each tab are programmatically determinable by assistive technologies.

## React + TypeScript Implementation

Here is a clean, production-ready React component implementing the accessible tabs pattern.

```tsx
import React, { useState, useRef } from 'react';

interface Tab {
  id: string;
  label: string;
  content: React.ReactNode;
}

interface AccessibleTabsProps {
  tabs: Tab[];
  ariaLabel: string;
}

export const AccessibleTabs: React.FC<AccessibleTabsProps> = ({ tabs, ariaLabel }) => {
  const [activeIndex, setActiveTabIndex] = useState(0);
  const tabRefs = useRef<(HTMLButtonElement | null)[]>([]);

  const handleKeyDown = (event: React.KeyboardEvent<HTMLButtonElement>, index: number) => {
    let newIndex = index;

    if (event.key === 'ArrowRight') {
      newIndex = (index + 1) % tabs.length;
    } else if (event.key === 'ArrowLeft') {
      newIndex = (index - 1 + tabs.length) % tabs.length;
    } else if (event.key === 'Home') {
      newIndex = 0;
    } else if (event.key === 'End') {
      newIndex = tabs.length - 1;
    } else {
      return;
    }

    event.preventDefault();
    setActiveTabIndex(newIndex);
    tabRefs.current[newIndex]?.focus();
  };

  return (
    <div className="tabs-container">
      <div role="tablist" aria-label={ariaLabel} className="tab-list">
        {tabs.map((tab, index) => {
          const isActive = index === activeIndex;
          return (
            <button
              key={tab.id}
              id={`tab-${tab.id}`}
              role="tab"
              aria-selected={isActive}
              aria-controls={`panel-${tab.id}`}
              tabIndex={isActive ? 0 : -1}
              ref={(el) => { tabRefs.current[index] = el; }}
              onKeyDown={(e) => handleKeyDown(e, index)}
              onClick={() => setActiveTabIndex(index)}
              className={`tab-button \${isActive ? 'active' : ''}`}
            >
              {tab.label}
            </button>
          );
        })}
      </div>
      <div className="tab-panels-container">
        {tabs.map((tab, index) => {
          const isActive = index === activeIndex;
          return (
            <div
              key={tab.id}
              id={`panel-${tab.id}`}
              role="tabpanel"
              aria-labelledby={`tab-${tab.id}`}
              tabIndex={isActive ? 0 : -1}
              className={`tab-panel \${isActive ? 'active' : ''}`}
            >
              {tab.content}
            </div>
          );
        })}
      </div>
    </div>
  );
};
```
